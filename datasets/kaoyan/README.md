# 考研数学一题库（1987—2023）

## 数据概况

题库来自用户指定的本地考研数学一 PDF，覆盖 1987—2023 年共 37 个年份，收录 **805 条题目**。题干取自《【合集】1987-2023年考研数学一纯真题版.pdf》，最终答案及已有解析取自配套“答案解析”目录中的 37 份年度 PDF。1987—1996 年的试卷二不收录。

本目录仅保留 `questions.jsonl` 与本说明。转换概况、收录规则和校验结论合并在此；单独的转换报告、校验报告及逐题校正依据文件已删除。

| 题型 | 数量 |
|---|---:|
| 选择题 | 253 |
| 填空题 | 229 |
| 解答题 | 285 |
| 证明题 | 38 |

- 原材料处理规模：题干 127 页，年度答案解析 442 页。
- 采用 MinerU 已登录网页精准解析的完整 JSON；免登录轻量 OCR 草稿未作为最终输入。
- 候选与正式收录均为 805 条；转换结束时待处理队列为 0 条。
- 47 条题目的 `answer.solution` 为空；原材料缺少解析时不补写推导，仍保留题目及最终答案。
- 54 条记录经过原页复核或用户授权的编辑、数学校正；这些修改不代表原材料官方解答。
- 题图与解析图共 **71 张**，统一存于项目根目录的 [`data/images/kaoyan/`](../../data/images/kaoyan/)，其中题图引用 24 张、解析图引用 47 张。

## 数据格式与使用

每行是一条 JSON 记录，顶层字段为 `id`、`question`、`answer`、`metadata`、`source`。

| 字段 | 含义 |
|---|---|
| `id` | 题目唯一标识，保留原有年份、分组和题号编码 |
| `question.text` | 题干文本及 LaTeX 公式 |
| `question.images` | 题干配图路径列表 |
| `question.options` | 选择题选项；其他题型通常为空列表 |
| `answer.final_answer` | 最终答案；原解答未单列简短结论时可能保留完整解答 |
| `answer.solution` | 原有解析及必要整理；缺少解析时为空字符串 |
| `metadata.paper_name` | 可确认的年份、卷名；无可确认卷名时使用 source |
| `metadata.question_type` | 选择题、填空题、解答题或证明题 |
| `source` | 固定为 `university_exam` |

所有图片路径均相对于项目根目录，例如 `data/images/kaoyan/文件名.png`。解析中的图片采用 Markdown 引用；读取时也应以项目根目录解析路径。

## 收录与整理规则

- 早期选择、填空小题按分组题号分别收录；解答大题保留全部小问，不按小问人为增加样本。
- 题干、答案与解析按年份、题型和原题号对齐。
- 合集第 111 页的位置错置，已依据年度解析归入 2010 年第 21—23 题。
- 2022 年合集缺少年份标题，依据配套解析中一致的题干和题号确认归属。
- 1997 年的重叠字形、残损编号按原页和年度解答整理。
- 2022 年第 2 题原稿存在重复选项，已采用用户人工修正的 C/D 选项，最终答案为 B；修正已同步至构建配置。
- 不编造学校、考试年份或官方解答身份。
