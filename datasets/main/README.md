# 主数据集

- `benchmark.jsonl`：128道高考评测题，全部有答案和解析。
- `training.jsonl`：1000道训练题，其中566道来自GAOKAO-Bench、434道来自Conic10K；训练集尚未逐题权威复核，不能直接当作严格测试集。

## 评测主集格式

每条记录包含 `id`、`source`、`question`、`answer`、`metadata` 五个顶层字段。选择题选项统一为 `{"label":"A","text":"选项内容"}` 对象。

| 题型 | 数量 |
|---|---:|
| 选择题 | 65 |
| 多选题 | 4 |
| 填空题 | 23 |
| 解答题 | 24 |
| 证明题 | 12 |

“选择题”表示单选，“多选题”表示多个正确选项；评测采用完整选项集合匹配，不因字母顺序不同判错，不新增漏选部分分规则。“综合题”“压轴题”在本评测主集中统一归为“解答题”，证明题保留。

卷名采用“年份＋已有卷别＋科目描述”的紧凑形式，仅规范已有信息，不补造未确认的文理科或官方身份。2026批次题干已去除题号前缀，已确认的OCR残片已整理为LaTeX。

两个mini子集的成员和顺序固定，不自动重建。修改主库中已有子集题目的内容或元数据时，须定向同步对应记录，并运行完整性校验。

本次整理保持128道题目的ID和最终答案不变。结构、公式解析及定向计算检查不等于全部题目已获独立数学证明。
