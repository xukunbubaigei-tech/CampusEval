## 三维帕累托前沿

同时以“准确率越高、Token 越少、耗时越短”为目标，目前位于帕累托前沿的模型有：

- **Qwen3-8B 非思考**：速度和 Token 最省，但准确率低，适合极低成本粗筛。
- **DeepSeek-V4-Flash 高思考**：93.75% 准确率、42,784 Token、5.4 分钟，是高准确率区间的综合性价比最优选择。
- **Qwen3.6-35B-A3B**：95.83% 为最高准确率，同时比同准确率的 Qwen3.6-27B 更快、略省 Token，适合准确率优先。

其余模型在这批共同题上均被至少一个模型同时从准确率、Token、耗时三个维度支配。例如 DeepSeek-V4-Flash 比 Qwen3-8B 受控思考更准，同时更省 Token、更快；Qwen3.6-35B-A3B 与 Qwen3.6-27B 准确率相同，但更快且略省 Token。

## 结论

1. **准确率优先**：Qwen3.6-35B-A3B 与 Qwen3.6-27B 均为 95.83%，但 35B-A3B 在共同题上耗时约为 27B 的 53%，Token 也略少，因此更优。
2. **综合性价比优先**：DeepSeek-V4-Flash 为 93.75%，只比最高成绩少 1 题，却比 Qwen3.6-35B-A3B 少约 58% Token、少约 53% 耗时。
3. **极低成本优先**：Qwen3-8B 非思考仅使用 13,555 Token、1.7 分钟，但准确率只有 58.33%，只能用于容错率较高的粗筛。
4. Qwen3-8B 开启受控思考后，准确率由 58.33% 提升到 91.67%，代价是 Token 增至约 5.7 倍、耗时增至约 10.9 倍，且旧运行有 11 道 API 失败。
5. DeepSeek-R1-Distill-Qwen-14B 完成率为 100%，但准确率只有 81.25%；DeepSeek-V4-Flash 同时更准、更快、更省 Token。
6. Qwen3-14B 与 Qwen3-8B 受控思考同为 91.67%，但前者约使用 2 倍 Token、2.1 倍时间，当前配置下没有效率优势。
