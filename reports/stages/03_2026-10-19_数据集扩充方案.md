## 1. 已确定的建设要求

1. 保留现有 Benchmark 128 条、training 1000 条，共 1128 条；不再添加高中、高考、奥赛等题目。
2. 中文新增题的唯一来源为用户提供的本地考研数学一、二、三真题及配套解析文件夹；其他中文高校、教材、社区、GitHub 或 Hugging Face 题库均不考虑，也不作为备用补缺渠道。该限制针对新增题，不删除现有题库。
3. 新增仅限大学高等数学、线性代数、概率论与数理统计，目标总库约 5000 道独立题目，按现有基线需新增 3872 道。
4. 本地中文考研题允许只有最终答案而无解析，answer.solution 留空，不补写原材料缺失的解析。英文候选仍按其原有配套解答要求筛选。
5. 接受 PDF 和扫描图片经 MinerU 转为文本与 LaTeX。扫描件本身不再是排除理由。
6. 题干、选项和必要图表应完整；有解析则保留，无解析则留空。原材料错误或答案缺失可按用户授权进行数学校正，修改前后内容及依据单独记录，不冒称官方解答。
7. 沿用现有 JSONL 核心格式，不建立强制的逐题独立索引。metadata.paper_name 缺失时，直接填与 source 完全相同的值。
8. “有原始解析”不等于“数学上必然正确”；OCR 结果及原解析均要核验，不能把识别完成当作正式入库完成。

- 所有其他中文来源均排除，包括此前提到的中文高校题答材料、社区试卷、MathBench/C-Eval/CMMLU 中文记录及其他考研网络仓库；不因有解析而重新列为候选。

- 只有课程目录、教材题号、资源宣传而无实际题答文件的来源，不计入有效供给。
- 小学、高中、奥赛及三门大学课程以外的题，不新增收录。
- 不采用“缺解析但可以生成”的替代路线。允许对已有解析进行格式转换、识别修复和经核实的勘误，不允许从零补写缺失解析后入库。

## 8. MinerU 到正式题库的流程

1. 文件盘点：按年份、卷种、课程整理材料，确认题干和原始解析均存在。中文先完成 A 类已知资料，再盘点同一本地资料总目录内其他卷种和年份；不扩展到外部中文材料。英文单独盘点 B/C 类。
2. 小批试转：优先选本地早期、近年两种 PDF，三门课程各取若干题。只选择原材料有解析的题，测试普通公式、矩阵、分段函数和多小问。
3. MinerU 初提取：获取 Markdown/公式文本，保留原文件。扫描 PDF 可以 OCR，但几何图、统计图不会因 OCR 自动变成自足题干。
4. 题答结构化：将题干、选项、最终结果和原解析关联；剔除封面、页眉、水印、考试说明等非题目内容。
5. 原页核对：确认上下标、积分上下限、矩阵行列、分布表、条件和跨页内容没有漏接。必要题图或图形答案无法可靠保留的题，本轮暂不收录。
6. 数学复核：对照推导检查结果，适用题辅助使用代回、符号和数值计算。原解析疑似错误的题先隔离，不能因来自真题资料而直接信任。
7. 跨源去重：同年数学一/二/三共用题、不同年度复用题、英文各渠道同题、随机和翻译变体不重复计数；外部中文网络题不采集。
8. 暂存审核：转换结果先入 staging/review，校验通过后再导入正式题库，并更新数量与 Manifest。

项目现有脚本 tools/mineru/extract_with_mineru_flash.py 会将 PDF 上传远程服务，保存 Markdown 和回执；它不是完整的分题、题答匹配或入库程序。远程接口当前可用性仍需试运行验证。材料有远程处理限制时改用本地解析方案；本文件重写不发起上传。

原始题目可能含答案标记和解析，需要从 question 中清除，避免把答案泄漏进模型输入。

## 9. 正式字段与来源规则

继续使用 id、source、question、answer、metadata，不增加强制逐题来源索引。

| 字段 | 规则 |
|---|---|
| id | 全库唯一且稳定；考研题可按卷种、年份、原题号组成，复导不重复 |
| source | 使用统一题源标识；新标识正式采用前同步修改 Schema 与来源校验 |
| question.text | 完整题干和小问，保留必要条件，剔除答案标记与解析 |
| question.images | 新增优先收无需题图的题，用 []；接受 OCR 不代表接受缺失必要图形 |
| question.options | 按原顺序保留选择题选项；非选择题为 [] |
| answer.final_answer | 从原解析整理完整结论，保留多解、范围与小问对应关系 |
| answer.solution | 有原解析时保存并校对；没有原解析时为 ""。原解析的授权校正单独记录依据，不声称官方解答 |
| metadata.paper_name | 有明确、非空的试卷名/题集名则保留；缺字段、null、空串或纯空白时，直接填 source，拼写完全一致 |
| metadata.question_type | 按现有 Schema 允许的六类题型映射，不能出现未支持的新值 |

示例：考研试卷卷名明确时可写“2023年全国硕士研究生招生考试数学一”；若某课程材料没有明确卷名，则 metadata.paper_name 使用该记录 source 的值。

当前 source 枚举仅含 gaokao、conic10k、aime、university_exam。真实考试题可按现有 university_exam 规则转换；若需区分考研和各课程题源，在实施时统一决定新增来源标识，并同步校验代码。本次不修改程序，也不将普通教材练习强行当作考试题。

下载信息、材料使用条件、解析勘误和审核结果可在批次说明中汇总，不恢复此前被否决的逐题额外索引要求。公开访问、用户持有文件与公开再分发使用条件分别核实，不能把未确认的材料称为“已获授权教材池”。
