# SOA 数据构建

定位原始题答边界并将整理内容转换为暂存题库。

| 文件 | 用途 |
|---|---|
| [prepare_soa_segments.py](prepare_soa_segments.py) | 定位原 PDF 题答边界、提取答案及选项信息，并定义排除题号 |
| [build_soa_dataset.py](build_soa_dataset.py) | 将提取内容与纠错配置转换为暂存题库；本身不直接发布正式 SOA 文件 |

命令建议从项目父目录 `D:\codex-project\高考数据集` 执行；使用此目录下的新路径。


这些工具可能下载或上传原材料，或写入题库、图片、报告；按具体脚本用途运行。重新构建仍需相应原始文件与中间材料。

## 后续提取规范

后续采用网页端精准解析并下载 JSON，保存到 `workspace/<解析内容名称>/`，题干与答案解析分别命名。详见 [workspace 标准流程](../../../workspace/README.md#网页端精准解析标准步骤)。现有 SOA 构建器读取固定文件名模式，新批次需要相应适配。
