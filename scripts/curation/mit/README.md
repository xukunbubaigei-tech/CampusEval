# MIT 人工整理题答

构建器读取的题干、答案及解析内容；这些文件属于维护输入，不是缓存。

| 文件 | 用途 |
|---|---|
| [mit_curated_calculus.py](mit_curated_calculus.py) | MIT 首批微积分题答，由 `build_mit_dataset.py` 读取 |
| [mit_curated_algebra_stats.py](mit_curated_algebra_stats.py) | MIT 首批线代、概率统计题答，由 `build_mit_dataset.py` 读取 |
| [mit_batch2_probability.py](mit_batch2_probability.py) | MIT 第二批概率题答，由 `extend_mit_dataset.py` 读取 |
| [mit_batch2_statistics.py](mit_batch2_statistics.py) | MIT 第二批统计题答，由 `extend_mit_dataset.py` 读取 |
| [mit_batch2_calculus_algebra.py](mit_batch2_calculus_algebra.py) | MIT 第二批微积分、线代题答，由 `extend_mit_dataset.py` 读取 |
| [mit_batch2_final_statistics.py](mit_batch2_final_statistics.py) | MIT 第二批期末统计题答，由 `extend_mit_dataset.py` 读取 |

命令建议从项目父目录 `D:\codex-project\高考数据集` 执行；使用此目录下的新路径。
